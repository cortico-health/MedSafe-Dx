# v0.3 arm-4 audit: why the flag misses the target

Date: 2026-09-26. Inputs: the arm-4a and arm-4b runs of the prompt test (`results/v03/ab/runs/*-v7a4[ab].json`; spec/v0.3-scoring.md draft 3, section 12). Script: `scripts/analysis/v03_arm4_audit.py`, which writes every audited case to `results/v03/ab/arm4-audit.json`. No model was called.

This audit matters because arm 4 scored far below arms 1-3 in draft 3 (docs: `results/v03/ab/ab-report.md`, finding 4), and we need to know whether the flag misses serious patients or names a different serious condition. The first means the model fails; the second means the draft-3 rule over-charged it.

## What we audit

We take every SERIOUS case (90 per row) whose flag does not name one of the case's R10 targets under the standard map with the family rows. We give each case one class, testing the flag first, because the flag is the arm's decision:

| Class | Rule, in order of testing |
|---|---|
| ii | the flag names a different tier-1 DDXPlus condition |
| iii | the flag names no DDXPlus condition (off-list); split by its tier in spec/offlist_tiers_nhamcs.csv (1, 2, 3, unscored). Only tier 1 counts as a serious reason |
| v | key artefact: every R10 target is DXA-derived, and the flag or the top diagnosis names the true, not tier-1, condition |
| i | the target is in the model's own list, but a benign condition or null is flagged |
| iv-b | a different serious condition is in the list, but a benign condition or null is flagged |
| iv | no serious condition anywhere in the answer: a genuine miss |

Classes i, iv-b, iv and v hold only benign flags (tier 2-3 DDXPlus conditions) and null flags. The off-list tier file is the NHAMCS-derived file committed at 9323b23 (sha256 3d4f73d04064...), which includes the Newman-Toker 2023 and AHRQ 2022 overrides.

## Findings

1. **Terra and OSS rarely miss outright; they flag a different serious condition.** Class ii is 20-27 cases per row, and in about half of them the target sits in the model's own list. Of their 95 class-ii flags, 46 are pulmonary embolism (I26) and 26 acute coronary syndrome (I20-I24), mostly on chest-pain cases whose target is pneumothorax, myocarditis, pulmonary oedema or Boerhaave. Genuine misses (class iv) are 0-2 per row.
2. **Their off-list flags are mostly tier 1.** Aortic dissection (I71.0) on Boerhaave and pneumothorax cases, stroke (I63) on Guillain-Barré, subarachnoid haemorrhage (I60.9) on a PSVT case with headache, lymphoma and laryngeal cancer on Chagas and pharyngitis cases. The NHAMCS file now credits these, which the draft-3 Newman-Toker groups mostly did too; it adds acute pancreatitis (K85) and GI haemorrhage (K92.2).
3. **Llama's flag is its top diagnosis, not a concern.** Of its 52 arm-4a class-iii flags, 24 are unscored codes (hypochondriasis F45.2, erythema multiforme L51), 13 are tier 3 (low back pain M54.5, cervicalgia M54.2) and 5 tier 2 (sleep disorder G47.9); 10 are tier 1. Most of Llama's class iii is a miss, not a partial.
4. **Key artefacts are 1-8 cases per row, and they concentrate in three truths.** Myasthenia gravis with a DXA-derived Guillain-Barré target, where the model flags myasthenia itself (G70.0); tuberculosis and HIV with a DXA-derived pulmonary or pancreatic neoplasm target. Terra 4a has 8, about a fifth of its audited cases. These cases charge a correct diagnosis for not naming a DXA concern.
5. **Class i (target listed, benign flag) is rare: 0-3 per row.** A flag that points at the target when the target is already listed would add little; the gap is the choice between serious conditions (class ii), not a failure to flag at all.
6. **Some tier-file entries look too high for a rule-out flag.** The file puts type 2 diabetes (E11), unspecified viral hepatitis (B19) and interstitial lung disease (J84) in tier 1, so Llama flags of E11, B19 and J84 on SERIOUS cases count as partials (6 cases). We report them rather than override the file, because its owner should decide.

## Limits

- The class order decides the overlaps: a case with a tier-1 flag is class ii even when it is also a key artefact. The JSON keeps `target_listed`, `dxa_only` and `top1_truth` per case, so other orders can be counted.
- "Serious" for off-list flags is the tier file's tier 1; rerun the script when the file changes.
- The audit covers the three models that ran on the 150 cases; Claude Haiku 4.5 ran only the smoke.
